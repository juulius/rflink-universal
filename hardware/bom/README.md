# Bill of Materials (BOM) — planned

A BOM is the complete list of parts required to assemble the RFLink Universal PCB.

**No verified BOM is published yet.** Do not order parts from an unverified list.

A future BOM should include, at minimum: board revision, reference designator, quantity, value/description, package/footprint, manufacturer part number (if confirmed), approved substitutes and notes. Prices and supplier availability should be dated when supplied, not guessed.

Match every BOM reference designator and footprint to the same KiCad schematic/PCB revision. Keep local/personal procurement records out of this public repository.
