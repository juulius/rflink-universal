# References / attribution

The prototype implementation is freshly written for RFLink Universal and uses the public RAMSES-II format, including the Manchester nibble table and header flag table, cross-checked against:

- Henry (Processware), `me-processware/orcon-15rf-controller` (2026), MIT license: https://github.com/me-processware/orcon-15rf-controller
- Protocol notes: https://github.com/me-processware/orcon-15rf-controller/blob/main/docs/PROTOCOL.md
- Known command examples: https://github.com/ramses-rf/ramses_cc/wiki/5.2-Faking-Remotes-(switches)
- Original Orcon decoder and tests (GPL-3.0): https://github.com/peeter123/orcon-15rf-protocol-decoder – **reference only, no copied GPL source code**.
