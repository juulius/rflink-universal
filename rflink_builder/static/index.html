Previously compiled versions

Reuse a previous successful build without recompiling. Only verified files matching the current board profile can be selected.

Older firmware may not understand newer device settings. ESP-IDF anti-rollback or a changed partition table can prevent a downgrade. USB and OTA are restricted to a separate test board until validated.
